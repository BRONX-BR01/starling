# iaf_dragon

Ice and Fire fire dragon for Horizon/Starling (stage 1: model, textures, walk/flight poses).

- Spawn: `/firedragon [red|green|bronze|gray]`
- Needs the content mod `iceandfire_dragon_items.hmod` (v0.2+), which carries the dragon textures.
- Model and textures from Ice and Fire (Alexthe666 / Iceandfire team), used under their license.
